DESKTOP HELPER

Browser companion

A private unpacked Chrome extension for capturing a public business page you open yourself.

⌘

LOCAL INSTALL · DESKTOP CHROME

Capture one page at a time

The companion can extract visible contact details from a public business website after you click Capture. It exports a JSON file you can import here.

  1. Download or clone this GitHub repository on your computer.
  2. Open chrome://extensions and turn on Developer mode.
  3. Select Load unpacked and choose the extension folder.
  4. Open a public business website and click the extension to review/export the capture.

MAPS SEARCH

Google Maps opens; its listings stay there

Google’s terms prohibit scraping and copying Maps business listings into another database. The companion will block extraction on Maps pages. Use the local open-data route here, or a properly licensed API for other data.

DATA HANDLING

Raw documents are temporary

The worker parses fetched PDFs in memory, keeps the source URL and relevant text evidence, and discards the PDF bytes. Candidate emails are never generated from guessed name patterns. An email found in a filing is labeled as a filing contact and requires review.
