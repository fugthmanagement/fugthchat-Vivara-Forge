LOCAL INSTALL · DESKTOP CHROME

Capture one page at a time

The companion can extract visible contact details from a public business website after you click Capture. It exports a JSON file you can import here.

  1. Download the companion files on your computer.
  2. Open chrome://extensions and turn on Developer mode.
  3. Select Load unpacked and choose the extension folder.
  4. Open a public business website and click the extension to review/export the capture.

MAPS SEARCH

Google Maps opens; its listings stay there

Google’s current Maps terms prohibit copying business names, addresses, or reviews from Maps into another database. The companion blocks capture on Maps pages. Use the local open-data route here, or a properly licensed API for other data.

DATA HANDLING

Temporary documents, recoverable records

The worker parses fetched PDFs in memory, keeps the source URL and relevant text evidence, and discards the PDF bytes. Contact details are never generated from guessed patterns. Use Download full backup from Prospects to save a restorable JSON copy of current prospects, evidence, job history, and sanitized diagnostics.
